# 演示脚本（本机演示环境）

> 用途：大赛现场/录屏演示的分镜脚本。每步给出命令、预期输出与兜底分支。
> 前置：Python 3.12、已安装 `backend/requirements.txt`、`frontend/node_modules` 已就绪；Docker 可选（无 Docker 仍可完成本脚本）。
> 实测基线：2026-11-20 全流程 10 项检查 PASS（证据 `.evidence/competition-delivery/c01-demo.log`）。

## 0. 演示前检查（30 秒）

| 步骤 | 命令 | 预期 |
|---|---|---|
| 依赖就绪 | `python -c "import sys;sys.path.insert(0,'backend');from app.config import load_config;load_config();print('config ok')"` | 输出 `config ok`，退出码 0 |
| 仓库状态 | `git log --oneline -1`、`git status --short` | 有提交号；工作区无输出 |

**兜底**：若 `config ok` 失败，直接展示 `.evidence/competition-delivery/b01-recalc.log` 的已知通过记录，并说明"演示环境依赖未就绪"，不得伪造运行画面。

## 1. 空转闭环（60 秒）

```bash
python scripts/smoke_m0.py
```

预期关键行：`[smoke] chain_valid=True`、`[smoke] PASS`，退出码 0。

讲解点：状态机 T1 → T4 → T17 迁移、事件链 4 条且校验通过、缺失步骤 4 个如实列出。

**兜底**：失败时展示 `.evidence/competition-delivery/b01-smoke.log`，说明失败步骤，不重试到成功为止。

## 2. 十个入口与闭环演示（4 分钟）

```bash
python scripts/demo_rehearsal.py
```

预期 10 项全部 PASS：

| # | 检查项 | 讲解点 |
|---|---|---|
| 1 | 入口1 人工提交 | `POST /api/v1/issues` 返回 202 与 issue_id |
| 2 | 入口2 定时扫描（幂等） | 同一窗口重复触发返回 `VF-1003` |
| 3 | 入口3 Repo Webhook | 签名校验后的入库路径 |
| 4 | 入口4 CVE 订阅 | 依赖漏洞通道 |
| 5 | 入口5 运行时告警 | 运行时通道 |
| 6 | 判定→复现→补丁→审计 | 四段串联，含六条 diff 审计 |
| 7 | 回放七步 | `steps=7 events=7 chain=True` |
| 8 | 熔断与解除 | `VF-6001` → CLOSED |
| 9 | 暂停与恢复 | 自动处置暂停、任务排队 `QUEUED_BY_PAUSE` |
| 10 | 看板六类要素 | 在办数/级别分布/熔断状态/连续自运行/失败原因 Top N/指标 |

**重要**：该脚本会写入 `docs/devlog/m4-demo-report.md`。演示后必须执行 `git checkout -- docs/devlog/m4-demo-report.md` 恢复历史报告；本轮已如此处理，恢复后 sha256 校验为 OK。

**兜底**：若某入口失败，展示失败项并说明原因，**不得把失败项口头说成通过**。

## 3. 指标复算（2 分钟）

```bash
python scripts/recalc_metrics.py --window 2026-12 --tier PRELIMINARY \
  --now 2027-01-06T12:00:00+00:00 \
  --report-path .evidence/competition-delivery/metrics-report-rerun.md \
  --evidence-root .evidence/competition-delivery/metrics-recalc
```

预期：退出码 0，M4=0.6667、M5=1.0000、M6=0.0000、M7=30min、M8=0.6667，M9 为"未验证（EVIDENCE_MISSING）"，报告结论 **UNDETERMINED**。

讲解点：为什么要标 UNDETERMINED、为什么 M9 不能写 0（见 `deliverables/指标口径表.md` §3）。

**兜底**：若报"混合定义版本"，说明默认参数未指定窗口关闭时间，改用上面的标准参数；不得改成 v1 口径凑数值。
